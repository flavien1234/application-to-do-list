# Mes tâches — application to-do list

Une application simple pour organiser tout ce que j'ai à faire, réparti en trois catégories :

- 📚 **Cours**
- 💼 **Alternance**
- 🏠 **Perso**

## Utilisation

Ouvre `index.html` dans ton navigateur (double-clic sur le fichier). Pas besoin d'installation ni de connexion internet.

Les tâches sont enregistrées automatiquement dans le navigateur (localStorage) : elles restent là quand tu fermes et rouvres la page, **sur le même navigateur et le même appareil**. Pense à faire un export de temps en temps (menu `⋯` → *Exporter*) pour garder une sauvegarde ou passer sur un autre appareil (*Importer*).

## Fonctionnalités

- Ajout rapide d'une tâche avec catégorie et date d'échéance
- Onglets par catégorie avec compteur de tâches restantes
- Regroupement automatique : *En retard*, *Aujourd'hui*, *Cette semaine*, *Plus tard*, *Sans échéance*
- Clic sur une tâche pour la modifier : priorité, matière/projet, notes, sous-tâches
- Recherche, filtre (à faire / terminées / toutes) et tri (échéance, priorité, plus récentes)
- Annulation possible après avoir terminé ou supprimé une tâche
- Thème clair / sombre
- Export / import JSON
- Adapté au téléphone
